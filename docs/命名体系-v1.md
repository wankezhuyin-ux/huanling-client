# 命名体系 v1 · 以画喻武

> 《墨境》的命名总纲。世界上的一切都用**一支笔、一张纸、一池墨**来解释：
> 武功是笔法，丹药是颜料，地图是画境，宠物是墨生灵兽。
> 这样玩家不需要看文案也能感觉到"这是一款讲水墨的游戏"，而不是给老游戏换了层皮。

## 一、总原则

1. **一条内核**：凡力量皆有笔法对应（提按、中锋、侧锋、飞白、破墨、皴擦）。
2. **可猜**：名字要能让玩家猜出效果方向（防御类用"罩/固/护"，攻击类用"劈/破/焦"）。
3. **不撞**：不用任何真实作品名、门派名、人物名、名画名、现代商标。
4. **键不动**：物品**内部 id 一律不换**，只换 `name` 显示字段。
   - 背包、邮件、交易、帮派仓库存的是 id；换 id 会让老玩家东西变"未知物品"。
   - 换皮换的是玩家看得见的字，不是数据库里的钥匙。

## 四、验收方式

```bash
# 武学池两边是否一致（不一致退出码 2）
python3 tools/sync_martial_pool.py --check

# 服务端抽名是否正常
cd ../deploy/server && python3 -c "import handlers_growth as h; print(h.roll_martial_art('地仙', set()))"

# 客户端能否整体加载
Godot --headless --path . --quit
```
