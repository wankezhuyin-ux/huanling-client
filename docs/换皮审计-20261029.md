## 二、施工批次

> 原则：**先改名与文案（零美术成本、玩家最快感知），再重制美术与音频，最后重构代码**。每批独立可上线、可回滚。

| 批次 | 内容 | 产出 | 状态 |
|---|---|---|---|
| **B0 地基** | 术语字典 `rename-map.json`（旧名→新名，全工程唯一真源）；改名/迁移工具链 | 字典 + 脚本 | 进行中 |
| **B1 文案换名** | 288 宠物 / 279 地图 / 289 道具 / 21 套装 / 技能 / 怪物 / 系统名 / 境界 / 活动；客户端+服务端+存档三端迁移 | 新数据表 + 迁移脚本 | 待开始 |
| **B2 标识清理** | 群号、玩家昵称、包名、版本号、「原版」注释、发布包内文档 | 干净包 | 待开始 |
| **B3 美术重制** | 1536 张：背景 134 → 宠物 342 → 战斗帧 696 → 道具 205 → 其余。统一画风表 + 批量重绘管线 | 新图集 | 待开始 |
| **B4 音频重制** | 17 首 BGM 全换 | 新曲库 | 待开始 |
| **B5 代码重构** | 169 个文件改名改结构、去原版命名与注释；关键模块按自有架构重写 | 新代码树 | 待开始 |

### 验收标准（每批必过）

1. `grep` 全仓无原游戏专有名词、无 IP 名、无群号、无真实玩家昵称。
2. 解包 pck 看不到与原版同名的资源路径。
3. 客户端 `--smoke` 无 SCRIPT ERROR，主城/战斗/背包/邮件/生死塔跑通。
4. 旧存档迁移后宠物、道具、装备不丢不错位。
