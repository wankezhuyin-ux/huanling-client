# 恢复工程开发副本

169 个 GDScript 与 1714 个导入资源均已由 GDRETools 恢复。恢复原样归档在上级 `原始恢复工程.zip`。

本副本仅改了服务器默认主机为 127.0.0.1，并添加 local_server_override.json，便于后续接入自有测试服。这不是已经实现的服务端。手机中的 127.0.0.1 指向手机本身，真机测试时需设置测试服务器的局域网地址。

原生库标识 Godot 4.6.1，自带 project 配置 features 为 4.6；GDRETools 把字节码归为兼容的 4.5.0-stable。优先用 Godot 4.6.1 做首次兼容性验证，不要将恢复工具提示视为已验证可运行。

145 项资源被恢复工具标记为 lossy，可能无法还原原始质量。完整日志在 gdre_export.log。尚未运行游戏、进行导出构建、真机或联网验收。

原美术、音乐仅用于分析和替换定位，其修改与商业使用授权未确认。发布前请完成原创替代制作与来源记录。代码授权由用户确认，授权范围需随项目保存。

后续先实现账号、角色、存档、战斗与奖励的最小联网闭环。独立服务器、数据库、运营后台、签名、支付和发行配置均未包含在 APK 恢复成果中。
