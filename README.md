# 幻灵归虚 / 水墨灵兽 · 客户端

Godot **4.6.1** 客户端主工程。由 GDRETools 从 APK 恢复（169 个 GDScript、1714 个导入资源），
之后做了本地化层、水墨换皮、横版战斗、三页 UI 重构。

> **这不是可以直接对外发布的工程。** 原版美术/音乐/字体/反编译代码的授权都还没完成，
> 发布前必须做原创替代。详见 [`README-开发前必读.md`](README-开发前必读.md) 与
> [`版权与脱敏审计台账-2026-11-09.md`](版权与脱敏审计台账-2026-11-09.md)。

## 三个仓库的关系

本项目拆成三个独立仓库，**这个是主交付物**：

| 仓库 | 是什么 | 语言 |
|---|---|---|
| `huanling-client` ← **你在这里** | Godot 客户端（169 个脚本、52 个 UI） | GDScript |
| `huanling-server` | 自建服务端，实现客户端用到的 177 个接口 | Python 3 标准库 |
| `huanling-ui-kit` | 从概念图拆出来的 UI PNG + 九宫格切边 + 装配验证台 | 素材 / Python |

服务端和 UI 套件都是为这个客户端服务的，客户端本身**一行协议都没改**。

## 跑起来（3 步）

```bash
# 1) 先起服务端（另一个仓库）
git clone <server 仓库地址> && cd huanling-server
python3 server.py                 # 3000 API / 3001 聊天，只需 Python 3.9+

# 2) 再开客户端
git clone <本仓库地址> && cd huanling-client
godot --path .                    # 或用 Godot 4.6.1 编辑器打开

# 3) 走一遍：登录 → 主城 → 战斗 → 背包
```

- 默认入口 `main.tscn` → `ui/ink_home.tscn`（水墨首页）
- 本地联调入口 `dev/local_preview.tscn`
- 服务器地址在 `scripts/game_server_config.gd` 的 `API_PUBLIC_HOST`（默认 `127.0.0.1`），
  可被根目录 `local_server_override.json` 覆盖（该文件不入库）

## 结构（不要随意移动）

| 路径 | 作用 |
|---|---|
| `scripts/` | 104 个 `.gd`：战斗、背包、装备、炼器、法宝、宗门、竞技场、聊天…（`network.gd` 约 10083 行、178 处 `server_url`） |

## 三条红线

1. **不要在恢复出来的脚本里加 `if local` 分支。** 本地功能全部挂在 `dev/` 层，
   `scripts/` 保持原样，方便以后与原版逐行对比。
2. **`.gitignore` 里的东西不要硬加**：`.godot/`（可重建）、`local_server_override.json`（本机配置）、
   `tools/`（开发期采集与审计工具）、`dev/local_snapshot.json`（线上快照）。
3. **美术替换要过审计。** 哪些图还是原版字节、哪些已自制，查
   [`版权与脱敏审计台账-2026-11-09.md`](版权与脱敏审计台账-2026-11-09.md) 与
   [`asset_copyright_inventory.csv`](asset_copyright_inventory.csv)（2305 行，按批次/优先级筛选）。
